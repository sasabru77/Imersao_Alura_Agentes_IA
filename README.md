# 🧮 Imersão Calculadora IA

Calculadora simples em Python desenvolvida para a **Imersão Alura Agentes IA**.
Ela possui as 4 operações matemáticas básicas e um agente de inteligência artificial (**Alura IA**) que sugere o próximo passo de cálculo com base nos seus resultados anteriores.

---

## 📁 Arquivos do Projeto

* **`calculadora.py`**: Funções das 4 operações (adição, subtração, multiplicação e divisão).
* **`agente_ia.py`**: Inteligência da Alura IA que analisa o histórico e sugere os próximos passos.
* **`main.py`**: Programa interativo para rodar no terminal.
* **`app.py`**: Ponto de entrada direto.
* **`testes.py`**: Testes simples para conferir se tudo está funcionando.
* **`requirements.txt`**: Dependências do projeto.

---

## 🚀 Como Rodar

### 1. Iniciar a Calculadora
No seu terminal, digite:
```bash
python main.py
```

### 2. Rodar os Testes
Para testar as operações:
```bash
python testes.py
```

---

## 🤖 Como a Alura IA Funciona

1. Você digita um número e escolhe uma operação (`+`, `-`, `*`, `/`).
2. Após o resultado, a **Alura IA** sugere até 3 opções lógicas (ex: aplicar 10% de desconto, parcelar em 2x ou 3x, etc.).
3. Basta digitar `1`, `2` ou `3` para aplicar a sugestão direto na conta!
